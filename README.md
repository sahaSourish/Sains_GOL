# Groceries Support Hub — v4
The calculator now generates a customer-facing refund statement from the calculated result.

It distinguishes:
- Original payment card refunds
- eVouchers
- Substitution Price Promise eVouchers
- Mixed refund + voucher outcomes

The calculator shows the calculated amount and a timeframe statement. For card refunds, the current public Sainsbury's online-grocery terms state 3–5 working days for applicable refunds. For substitution eVouchers, the published terms state a 2-month validity period; the tool deliberately does not invent a universal issue-time guarantee where the public source does not state one. The agent should use the current internal process for the actual method/timeframe they are authorised to quote.

Sources checked:
- https://help.sainsburys.co.uk/help/terms-and-conditions/buying-online
- https://help.sainsburys.co.uk/help/terms-and-conditions/substitution-promise-t-cs
- https://help.sainsburys.co.uk/help/ordering/out-of-stock-before-delivery
- https://help.sainsburys.co.uk/help/offers-promotions/meal_deal

This is an agent-assist tool, not a replacement for current internal SOPs, live order/payment systems or colleague guidance.
